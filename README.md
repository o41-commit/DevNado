## Overview

**DevNado** is my personal portfolio website, showcasing selected projects, practical engineering skills, and the products I build as a full-stack developer. The goal is simple: present work clearly, make it easy to explore, and connect with people who need useful web or mobile products.

## What you'll find

- **Selected projects** — real-world websites, applications, dashboards, and product experiences.
- **Full-stack development** — frontend interfaces, backend APIs, data-driven features, and integrations.
- **Responsive UI** — layouts designed to work across desktop, tablet, and mobile screens.
- **Product thinking** — a focus on usability, clarity, maintainability, and solving real problems.

## Tech stack

My work spans technologies including:

- **Frontend:** React, Vue.js, Angular, JavaScript, Sass
- **Backend:** Node.js, Express.js
- **Data:** MongoDB
- **Mobile:** React Native
- **Deployment:** Vercel and other project-appropriate platforms

## Run locally

This project uses a modern JavaScript frontend toolchain. To run it locally:

```bash
git clone https://github.com/o41-commit/DevNado.git
cd DevNado
npm install
npm run dev
```

If the scripts differ in the current project configuration, check `package.json` for the available commands.
